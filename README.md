# Gestión de Transporte Urbano - OOP2 Actividad 2

## Descripción

Proyecto Maven para el procesamiento de datos de transporte urbano.

## Requisitos

- Java 21
- Maven 3.9+

## Compilación y ejecución

```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="edu.iudigital.transporte.Main"
```

## Estructura del proyecto

```
src/main/java/edu/iudigital/transporte/
├── accion.java
├── registro.java
├── ProcesadorTransporte.java
└── Main.java
```
